## 工单判断（BBU 场景组审任务说明 — 自包含版）

### 1. 任务目标
- 输入：一组与通信机房 BBU 相关的图像（通常每组 1～N 张）。
- 输出：
  - Stage-A（逐图）：每张图输出一行中文摘要（仅一行）。
  - Stage-B（整组）：汇总所有摘要与预设检查提示，输出整体审核结论：
    - 通过：
```
总评: 通过
```
    - 不通过：两行
```
总评: 不通过
原因: <简要列出未满足的提示项或摘要中的问题>
```
- 场景限制：仅讨论并允许提及以下对象与属性：BBU设备、挡风板、螺丝/光纤插头、标签、光纤、电线。严禁引入无关设备或术语（如 PPDU、DCDU、ODF、CPRI 等）。

### 2. 数据与标注（SFT 训练一致）
#### 2.1 对象与几何
- 允许对象类型与几何：
  - bbu、bbu_shield、connect_point、label：bbox_2d 或 quad
  - fiber、wire：line
- 几何格式：
  - bbox_2d: [x1, y1, x2, y2]
  - quad: [x1, y1, x2, y2, x3, y3, x4, y4]
  - line: [x1, y1, x2, y2, ..., xn, yn]

#### 2.2 描述字符串（desc）结构
- 分隔符规范：
  - 逗号","：同一层级的多个属性之间使用逗号分隔
  - 斜杠"/"：不同层级（主属性/条件属性）之间使用斜杠分隔
  - 条件属性：只有当父条件满足时才出现（例如 bbu 需要挡风板时才出现是否按要求配备）
  - 自由文本：直接插入（不改写），例如标签文字、特殊情况说明
- 示例：
  - BBU 需要挡风板且已配备：
    - "BBU设备,华为,显示完整,机柜空间充足需要安装/这个BBU设备按要求配备了挡风板"
  - 光纤有保护且为蛇形管，弯曲合理：
    - "光纤,无遮挡,有保护措施,弯曲半径合理/蛇形管"

#### 2.3 对象属性与取值（规范化中文，训练已覆盖）
- bbu（BBU设备）
  - brand（品牌）：华为 / 中兴 / 爱立信
  - completeness（显示完整性）：显示完整 / 只显示部分
  - windshield_requirement（挡风板是否需要）：无需安装 / 机柜空间充足需要安装
  - windshield_conformity（挡风板是否按要求配备，条件属性，仅在需要安装时）：
    - 这个BBU设备按要求配备了挡风板
    - 这个BBU设备未按要求配备挡风板
  - special_circumstances（特殊情况，可选自由文本）

- bbu_shield（挡风板）
  - brand（品牌）：华为 / 中兴
  - completeness（显示完整性）：显示完整 / 只显示部分
  - obstruction（遮挡）：挡风板无遮挡 / 挡风板有遮挡
  - install_direction（安装方向）：安装方向正确 / 安装方向错误
  - special_circumstances（可选自由文本）

- connect_point（螺丝、光纤插头）
  - type（种类）：
    - BBU安装螺丝 / 机柜处接地螺丝 / 地排处接地螺丝 / ODF端光纤插头 / BBU端光纤插头
  - completeness（显示完整性）：显示完整 / 只显示部分
  - compliance（连接是否符合要求）：符合要求 / 不符合要求
  - specific_issues（具体问题，条件属性，compliance=不符合要求时出现；可多选，逗号分隔）：
    - 未拧紧 / 露铜 / 复接 / 生锈
  - special_circumstances（可选自由文本）

- label（标签）
  - text_content（标签文字，自由文本，可能缺失）

- fiber（光纤）
  - obstruction（遮挡）：无遮挡 / 有遮挡
  - protection（保护措施）：无保护措施 / 有保护措施
  - protection_details（保护细节，条件属性，protection=有保护措施时出现）：
    - 蛇形管 / 铠装 / 同时有蛇形管和铠装
  - bend_radius（弯曲半径）：
    - 弯曲半径合理 / 弯曲半径不合理（弯曲半径<4cm或者成环）
  - special_circumstances（可选自由文本）

- wire（电线）
  - obstruction（遮挡）：无遮挡 / 有遮挡
  - organization（整齐度）：捆扎整齐 / 分布散乱
  - special_circumstances（可选自由文本）

#### 2.4 记录结构（JSONL 每行）
- images: List[str] — 处理后的图像路径（通常每条记录 1 张图）
- objects: List[Object]
  - 一个对象仅填写一种几何（bbox_2d 或 quad 或 line）
  - desc: 按上述模板构造的规范化中文描述
- width, height: 图像尺寸
- meta: 可包含对象数量、线段点数、是否存在负面属性等统计信息（非强制）

### 3. 推理与输出
#### 3.1 Stage-A（逐图摘要）
- 约束：
  - 只输出中文自然语言短语，且仅一行
  - 禁止任何坐标或几何标记；不得出现任意特殊标记（例如 `<|...|>`）、尖括号`< >`、方括号`[]`、或坐标数字
  - 不要使用引号，不要机械罗列重复词（如“螺丝、螺丝、…”）
  - 内容聚焦 BBU 场景及上文列出的对象与属性
- 建议表达要点（可包含）：品牌、挡风板状态/安装方向/是否需要、连接合规性、标签可读性、光纤弯曲、电线整齐度

#### 3.2 Stage-B（整组审核）
- 输入：多张图的摘要行 + 当前任务的检查提示清单（见 4. 任务与提示）
- 判定：仅依据“摘要内容 + 检查提示”进行综合判断，不得臆造信息，不得引入非 BBU 场景内容
- 输出格式：
```
总评: 通过
```
或
```
总评: 不通过
原因: <简要依据，列出未满足的提示项或摘要中的问题>
```

### 4. 任务与提示（四类工单）
- bbu安装方式检查
  - BBU显示是否完整
  - BBU安装螺丝连接是否符合要求（无未拧紧/露铜/复接/生锈）
  - 标签是否清晰可读
  - 电线捆扎是否整齐
  - 光纤弯曲半径是否合理

- bbu接地线检查
  - 接地端子是否漏铜
  - 接地/地线相关标签是否清晰可见

- bbu线缆布放要求
  - 接地连接是否规范（机柜/地排处）
  - 光纤是否有保护（蛇形管/铠装），弯曲半径是否合理
  - 关键连接点标签是否清晰

- 挡风板安装检查
  - 如需要安装，挡风板是否存在且安装方向正确
  - 挡风板是否无遮挡

### 5. 覆盖性评估（训练数据 → 检查点）
- bbu安装方式检查
  - 覆盖：
    - BBU完整性 → bbu.completeness（显示完整/只显示部分）
    - 螺丝合规与问题细项 → connect_point.compliance + specific_issues（未拧紧/露铜/复接/生锈，对应“BBU安装螺丝”）
    - 电线捆扎 → wire.organization（捆扎整齐/分布散乱）
    - 光纤弯曲 → fiber.bend_radius（合理/不合理）
  - 部分覆盖：
    - 标签清晰度 → label.text_content 为自由文本；是否“清晰可读”只能通过是否存在有意义文本间接反映，缺乏显式布尔字段

- bbu接地线检查
  - 覆盖：
    - 接地端子是否漏铜 → connect_point.specific_issues 包含“露铜”（且 compliance=不符合要求）
  - 部分覆盖：
    - 接地/地线相关标签是否清晰可见 → 依赖 label.text_content 自由文本；无显式清晰度布尔

- bbu线缆布放要求
  - 覆盖：
    - 接地连接是否规范（机柜/地排处） → connect_point.type∈{机柜处接地螺丝, 地排处接地螺丝} 且 compliance
    - 光纤是否有保护、细项 → fiber.protection（有/无） + fiber.protection_details（蛇形管/铠装/同时）
    - 光纤弯曲半径 → fiber.bend_radius
  - 部分覆盖：
    - 关键连接点标签是否清晰 → 仍为自由文本，无显式清晰度布尔

- 挡风板安装检查
  - 覆盖：
    - 是否需要 + 存在性 + 安装方向 → bbu.windshield_requirement（是否需要） + bbu_shield（对象存在） + bbu_shield.install_direction
    - 遮挡情况 → bbu_shield.obstruction（挡风板无遮挡/有遮挡）
  - 未覆盖：
    - BBU 上下 1U 是否空置、相邻 BBU 间是否都安装挡风板、爱立信设备是否按需间隔 1U（这些需要机柜 U 位信息或跨对象邻接关系，当前数据与训练标签未提供）

> 结论：除“标签清晰度”为部分覆盖、以及“U 位/相邻关系/间隔 1U”等空间布局类检查未覆盖外，其余提示项均被训练数据良好覆盖，可用于训练与判定。

### 6. 示例
- Stage-A（逐图）摘要示例：
```
华为BBU设备显示完整，挡风板按要求配备且方向正确，接入螺丝规范，光纤弯曲合理，电线捆扎整齐
```
```
ZTE BBU显示部分，光纤未加保护且弯曲半径不合理，标签模糊
```

- Stage-B（整组）输出示例：
```
总评: 不通过
原因: 光纤未加保护且弯曲半径不合理；电线分布散乱；未见清晰标签
```

### 7. 实施建议与扩展
- 若需将“标签清晰度”从“部分覆盖”提升为“完全覆盖”，建议在数据加工阶段为 `label` 增加显式布尔字段（可读/不可读），并在训练阶段同步引入该字段。
- 如需覆盖机柜 U 位/相邻关系类检查，应扩展数据采集与标注（引入机柜结构信息或跨对象关系），并在训练与判定逻辑中加入对应规则。
