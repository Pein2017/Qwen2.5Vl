We updated label masking to include the assistant-closing `<|im_end|>` token in the unmasked labels and spans so it participates in loss. Change made in `src_new/data/dataset.py` within `_create_masked_labels_with_spans`: after detecting assistant content span `(start, end)`, we look ahead up to 5 tokens for `<|im_end|>` and extend the span to include it, unmasking labels for `[start:final_end]` and recording the span as `(start, final_end)`. This teaches the model to emit `<|im_end|>` and improves termination during generation. Verified via smoke test that label at the final `<|im_end|>` equals the token id (not -100).
