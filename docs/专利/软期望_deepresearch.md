# 基于软期望的视觉大语言模型（V-LLM）数字处理优化方法

## 1. 技术领域

本发明涉及人工智能及计算机视觉技术领域，具体是一种基于**软期望**（*soft expectation*）机制的视觉大语言模型（Visual Large Language Model, **V-LLM**）数字处理优化方法。该方法旨在解决现有V-LLM在处理需要精确数值（如边界框坐标回归）任务时所面临的架构限制和效率问题，提高模型在视觉定位任务中的精度和训练效率。

## 2. 背景技术

### 2.1 现有技术问题

随着视觉大语言模型在图像描述、视觉问答等任务中的应用日益广泛，将**目标检测**等需要精确数值输出的任务融入V-LLM成为新的挑战。然而传统方法在这方面存在若干不足：

1. **架构耦合与梯度瓶颈**：许多现有方案采用分离式架构，将一个大型语言模型（LLM）与一个独立的检测头组合。例如典型的检测架构如DETR，在LLM之外增加一个回归头来预测边界框坐标。这种设计导致：

   * **梯度流受限**：坐标回归通常由一个小型多层感知机（MLP）完成，仅输出4个坐标值。如此低维的输出限制了梯度的丰富表达，LLM主体的强大能力无法充分用于坐标预测。
   * **训练复杂性**：为了将模型输出的多个预测框与真实框对齐，需引入复杂的集合匹配算法（如匈牙利算法），这增加了训练难度和不稳定性。
   * **能力未充分利用**：LLM具备强大的数值和空间推理潜力，但分离式架构下，这种潜力未能在坐标预测中得到充分发挥。

2. **数值表示的局限**：传统坐标回归直接输出连续数值 (x1, y1, x2, y2)，缺乏对预测不确定性的表征。而在语言模型框架下，LLM原生处理的是离散的词元（token），如何让模型灵活输出精确数值成为难点。

   * 某些研究尝试将坐标值离散化为若干档位，再作为词元输出，例如将图像坐标归一化到0\~1，再量化为上百或上千个离散区间。这种方法虽可用离散token表示数值，但量化误差和离散预测的问题依然存在：模型只能选择最接近的离散bin，难以达到连续数值的精细度。
   * 纯离散表示下，模型对坐标的不确定性无法量化。如果模型对两个相邻bin都较为犹豫，最终仍必须硬决定一个bin作为输出，无法直接获知预测的不确定度。

3. **损失函数设计复杂**：在将视觉检测融入语言模型时，往往需要为语言生成和坐标预测分别设计损失函数：

   * 常规方案需要同时优化语言建模的交叉熵损失和坐标回归的回归损失，如何权衡二者成为难题。
   * 多重损失以及匹配算法的引入，使整体训练目标不统一，调参困难，优化不稳定。

### 2.2 现有技术方案

针对上述问题，目前业界有两类代表性的技术路线：

**（1）分离检测头的VLM架构**：典型方案是将视觉语言模型分为两部分：由视觉-语言编码器产生特征，由一个专门的检测头输出坐标。例如DETR方案中，检测头通常采用一个简单的全连接网络，将模型提取的图像特征映射为4个坐标值：

```text
# 分离式检测头的示意伪代码
DetectionHead:
    输入: 图像+文本融合后的特征 (hidden_state)
    通过一系列全连接层，将hidden_state映射为 (x1, y1, x2, y2)
```

这种方案中，每个待检测目标通常由模型输出一个向量表示，再经DetectionHead回归出边界框坐标。然而其弊端在于：**梯度仅通过低维坐标回归头反传**，限制了主干LLM对于坐标预测的参与度；同时需要对预测框和真值框进行匹配，依赖例如匈牙利算法的复杂过程，整体训练代价较高。

**（2）统一序列生成的检测架构**：为避免额外检测头的引入，一些研究尝试将目标检测转换为**序列预测任务**。例如Google提出的Pix2Seq方法将每个物体的边界框坐标和类别一并序列化为离散令牌，由一个图像条件下的语言模型依次生成：

* **序列化表示**：每个对象描述为固定长度的token序列，例如 `[y_{min}, x_{min}, y_{max}, x_{max}, class]`。连续坐标通过预先离散化为若干bins来表示。
* **训练方式**：模型以最大似然目标训练，相当于让语言模型在图像条件下生成正确的token序列。由于输出是有序序列，不再需要复杂匹配算法，对每个object随机排序训练即可。

这类方法将检测完全融合到生成式模型框架，简化了架构并取得了一定性能提升。然而纯离散序列生成仍然存在**固有不足**：

* **精度受离散化限制**：坐标精度取决于离散bins数量，bins过少则精度不足，过多则词汇量巨大、训练困难。
* **梯度利用不充分**：训练时采用交叉熵损失强制正确的离散token输出。模型的预测分布只有在**完全正确**时才不受惩罚，相邻bins的预测错误与相差很远的错误都会被等同对待。这不利于模型逐步逼近正确值，也无法直接鼓励**分布集中**在正确附近。
* **缺乏不确定性量化**：最终输出为确定的离散token，模型对目标位置的不确定性无法直观体现。

综上，现有技术要么在架构上对LLM能力利用不足、训练复杂；要么在数值表示上受限于离散化，难以兼顾精度和灵活性。本发明针对这些不足提出改进方案。

## 3. 发明内容

### 3.1 技术方案概述

本发明提出一种基于**软期望**的V-LLM数字处理优化方法，将坐标预测任务无缝集成到大语言模型的生成过程中，并通过软期望机制实现连续可微的数值预测。核心方案包括：

1. **统一词汇空间扩展**：在模型的词汇表中引入专门的**坐标令牌**，将边界框坐标的数值表示离散为高分辨率的序列令牌。通过设计特殊的开始/结束标记，将坐标预测转化为标准的**下一令牌生成**问题，使模型以与生成文本相同的方式输出坐标序列。

2. **软期望回归**：采用软期望（即**Soft Argmax**）机制处理离散坐标令牌的输出。模型对每一坐标维度输出一个概率分布，本发明利用该分布的**期望值**作为预测坐标，从而得到连续值。训练时，通过可微的期望计算结合适当的损失函数，引导模型产生逼近真实坐标的概率分布，而非直接预测一个离散值。

3. **统一的混合损失函数**：设计一种混合损失函数，能够**自动区分**普通语言令牌和坐标令牌，对二者分别应用不同的损失计算策略——对常规词元使用交叉熵损失，对坐标词元使用软期望损失。两个部分加权组合成单一的总损失，实现语言生成与坐标预测的**端到端统一训练目标**。

4. **非破坏性模型扩展**：通过扩展词汇表和嵌入层的方式引入新功能，不改动预训练模型的核心权重，从而保持原有模型的语言与视觉知识**不受破坏**。该方案仅增加极少量新参数，实现对预训练V-LLM的功能扩展，保证向后兼容性和参数效率。

5. **数据格式转换模块**（可选）：提供统一的数据预处理与后处理，将传统标注格式（如JSON中的边界框坐标）转换为模型所需的带有坐标令牌的文本输入，以及将模型生成的坐标令牌序列还原为数值坐标。这确保了本发明方法可以方便地应用在现有数据集和任务流程中。

### 3.2 技术方案详细描述

#### 3.2.1 词汇表扩展技术

**技术思想**：将坐标回归问题重新表述为序列生成问题，即让模型**生成**坐标序列而非直接输出坐标数值。为此，需要在模型的词汇表（Vocabulary）中加入新的标记以表示数值坐标。具体包括：

* **坐标值令牌**：表示坐标数值的离散刻度。例如将0\~1归一化范围离散为2048个刻度，则引入令牌 `<coord_0>` 到 `<coord_2047>` 分别表示可能的刻度值0,1,...,2047。这样坐标空间的精度达到约1/2047（约0.05%），足以精确表示bounding box的位置。
* **特殊分隔令牌**：用于标记坐标序列的结构，如 `<|box_start|>` 表示一个边界框序列开始，`<|box_end|>` 表示结束。对于拓展的几何形状，也可定义类似的开始/结束标记。

**实现方式**：利用预训练分词器/模型接口扩展词汇表，并增广模型的嵌入层尺寸以适配新词汇。本过程不改变原有词的嵌入，只为新词添加嵌入参数：

```text
# 词汇扩展的概念流程（伪代码）
extend_vocabulary(tokenizer, model, new_tokens):
    将 new_tokens 列表添加到 tokenizer 词汇表
    调整 model 的嵌入矩阵大小 = 原大小 + 新令牌数
    初始化新嵌入参数（例如随机初始化或0）
    保持原有词的嵌入权重不变
```

完成以上步骤后，模型即可识别并生成新的坐标令牌。例如，模型输出一个物体的描述时，可以这样表示：

```
“...，在图像左上角有一个螺丝” <|box_start|> <coord_100> <coord_200> <coord_150> <coord_250> <|box_end|>
```

上述序列中，`<|box_start|>`指示接下来是边界框坐标描述，`<coord_100> <coord_200> <coord_150> <coord_250>`依次代表归一化坐标(x1=0.100, y1=0.200, x2=0.150, y2=0.250)的量化令牌，`<|box_end|>`表示该边界框描述结束。对于多目标检测任务，模型可以在一句话中依次产生多个这样的序列段来描述多个物体，无需额外的匹配过程。

**技术优势**：

* *架构统一*: 不需要额外检测头，视觉定位完全融入语言模型的生成架构，模型将坐标预测视作一种“特殊语言”生成。
* *高分辨率梯度*: 相比传统4维回归直接输出，本方案通过**高维离散坐标空间**提供了丰富的梯度信号。每个坐标预测其实是对数千候选的概率分布预测，梯度在整个坐标空间上平滑传播，有助于模型更精细地调整预测。
* *支持复杂几何*: 通过扩展词汇，可以方便地支持其它形状的描述，例如多边形、多点线段等。只需为额外的点位增加相应数量的坐标令牌，以及设计相应的开始/结束标记，即可表示更复杂的几何结构，具有良好的扩展性。

#### 3.2.2 软期望回归技术

**技术思想**：采用**软期望**（Soft Expectation）也称**软Argmax**的方法，将模型对坐标令牌的输出转化为连续坐标值。模型对每个坐标维度输出的不是一个硬决定的单一token，而是一个在所有坐标token上的概率分布。通过计算该分布对应的期望值，可得到一个连续坐标预测，并以此参与损失计算。

**核心算法**：对于每个坐标预测，我们令模型输出\$\mathbf{z} = (z\_0, z\_1, ..., z\_{N-1})\$作为该坐标所有可能离散取值的logits，其中\$N\$为坐标令牌种类数（例如2048）。然后进行如下计算：

1. **软max概率分布**：将logits通过Softmax映射为概率：
   $p_i = \frac{\exp(z_i / T)}{\sum_{j=0}^{N-1} \exp(z_j / T)}, \quad i = 0,...,N-1,$
   其中\$T\$是温度参数，用于控制分布的陡峭程度（\$T\$越小，概率越趋向one-hot；\$T=1\$为标准Softmax）。得到概率向量\$\mathbf{p} = (p\_0, p\_1, ..., p\_{N-1})\$。

2. **计算期望坐标值**：将离散坐标取值看作0到\$N-1\$的序列，计算概率分布的期望：
   $\hat{c} = \sum_{i=0}^{N-1} i \cdot p_i.$
   这个期望值\$\hat{c}\$即为模型预测的连续坐标（对应归一化坐标的刻度值期望）。由于\$i\$代表量化刻度，可进一步换算成实际归一化坐标数值（如除以\$N-1\$）。该过程对logits是可微的，因为Softmax和加权求和都是可微操作。

3. **损失计算**：采用**L1回归损失**衡量期望值与真实坐标值\$c\_{\text{gt}}\$之间的差异：
   $L_{\text{reg}} = \left|\hat{c} - c_{\text{gt}}\right|.$
   此外，引入**焦点损失**（Focal Loss）作用在概率分布上，鼓励模型提高对真实坐标对应离散bin的置信度。设真实坐标量化后对应的最接近离散刻度为索引\$k\$（即理想情况下模型应将概率集中在\$p\_k\$处），则定义：
   $L_{\text{focal}} = -\,\alpha \,(1 - p_k)^\gamma \log(p_k),$
   其中\$\alpha\$是平衡因子，\$\gamma\$控制对难分类样本（低\$p\_k\$）的侧重程度。该项损失在\$p\_k\$较小时（模型未能将概率集中于正确bin）时惩罚更大，促使模型收紧分布。反之如果模型已高度确信（\$p\_k \approx 1\$），则损失趋近0。

4. **组合损失**：软期望模块的总损失为回归损失和焦点损失之和：
   $L_{\text{coord}} = L_{\text{reg}} + L_{\text{focal}}.$

以上算法过程可用伪代码描述如下：

```text
# 软期望回归损失计算（单个坐标维度）
compute_soft_expectation_loss(logits, target_coord):
    p = softmax(logits / T)               # 概率分布
    expected_index = Σ (i * p[i])         # 期望刻度值
    L_reg = | expected_index - target_index |   # L1回归损失（target_index为真实坐标量化后的刻度）
    k = target_index
    L_focal = - α * (1 - p[k])^γ * log(p[k])    # 焦点损失，促进分布集中
    return L_reg + L_focal
```

**技术优势**：

* **连续可微**：通过期望操作，实现了从离散概率分布到连续值的无缝过渡，整个预测过程对模型参数是友好的、可微分的，这意味着我们可以直接通过误差的连续度量来反传梯度。相比离散分类误差只能告诉模型“对或错”，连续误差还能反映“错了多少”，从而给模型更丰富的学习信号。
* **精度和不确定性**：输出分布的方差反映了模型不确定性：如果模型对坐标不确定，概率会分散，期望值虽然可能正确但伴随大的方差；若模型高度自信，概率峰值尖锐。这样在推理阶段，本方法除了给出坐标预测值，还**自然提供不确定度量化**信息，可用于下游决策（例如，仅在模型高置信度时才采取行动）。
* **梯度平滑**：软期望避免了“硬分类”带来的梯度不连贯问题。传统交叉熵只能告诉模型预测正确与否，无法奖励“接近正确”的预测。而软期望下，即使模型当前预测的概率峰值偏离真实bin一些，只要期望值更接近真实值，L1损失就会相应降低，模型得到正向反馈，从而逐步逼近正确值。

#### 3.2.3 统一的混合损失函数技术

**技术思想**：为了同时训练模型的语言生成能力和坐标预测能力，本发明设计了一个**混合损失函数**。该损失函数根据输出令牌的类型自动切换相应的计算策略：

* 对于**普通文本令牌**（如描述性文字、标点等），使用标准的语言建模损失（例如交叉熵损失）来计算模型预测与目标词的差异。
* 对于**坐标类令牌**（包括坐标值令牌和相应的特殊标记），使用上一节描述的软期望回归损失来计算预测分布与真实坐标的差异。

**识别机制**：通过设定坐标令牌的ID范围，可以简单判断一个令牌是否属于坐标范围。例如，如果新加入的坐标令牌ID连续分配在区间\[M, N)（M为第一个坐标令牌ID，N为坐标令牌结束ID），则模型在计算损失时对每个位置\$i\$检查标签\$y\_i\$：

* 若 \$M \le y\_i < N\$，则该位置属于坐标令牌，用软期望损失计算。
* 否则，用交叉熵损失计算语言损失。

**混合损失计算流程**：

```text
# 混合损失计算示意（针对单个样本序列）
compute_hybrid_loss(logits, labels):
    total_loss = 0
    for position i in sequence:
        yi = labels[i]
        logit_i = logits[i]  # 模型对当前位置输出的预测分布(logits)
        if yi 是坐标类令牌:
            # 计算坐标损失 (soft expectation)
            coord_val = 对应的真实坐标值（根据令牌反量化得到）
            loss_i = soft_expectation_loss(logit_i, coord_val)
            weight = w_coord   # 坐标损失权重
        else:
            # 计算语言交叉熵损失
            loss_i = cross_entropy_loss(logit_i, yi)
            weight = w_lang    # 语言损失权重
        total_loss += weight * loss_i
    return total_loss
```

其中\$w\_{coord}\$和\$w\_{lang}\$是可调的权重超参数，用于平衡语言部分和坐标部分的损失贡献（通常可以都设为1以同等对待）。

**技术优势**：

* **端到端统一**：有别于传统需要分别训练检测分支和语言分支的方法，此混合损失将两种任务融为一体。模型通过**单一的训练过程**同时学习看图说话和精确定位，训练流程简单清晰。
* **自动分配**：损失函数无需人工干预地判别令牌类型，针对性地应用合适的损失。数据集标注是什么形式，损失就自动适应，无需对训练数据进行特别的拆分或配比调整。
* **易于权衡**：通过引入损失权重，可根据任务需要调整语言生成和坐标精度的重要性。例如在描述性任务中侧重语言流畅性，在定位任务中侧重坐标精度，具有很大的灵活性。

#### 3.2.4 非破坏性模型扩展技术

**技术思想**：充分利用预训练模型的强大能力，并避免重新训练整个模型。本发明的方案在实现新功能时**不改变原有模型权重**，而是以附加的方式扩展模型。具体做法包括词汇扩展和相应的新嵌入层参数，引入新的损失计算模块等，但预训练的Transformer主体、图像编码器等权重保持冻结或仅做轻微调整。

**实现方法**：

1. **词汇与嵌入扩展**：使用3.2.1节的方法扩展词汇表后，新加入的词需要新的嵌入向量。将模型原始词嵌入矩阵\$E\_{\text{orig}}\$复制一份，新矩阵\$E\_{\text{new}}\$的前面保留\$E\_{\text{orig}}\$不变，后面附加随机初始化的嵌入用于新词。类似地，如果模型有输出层权重（例如LM Head权重通常与嵌入共享或形状相同），也进行同样扩展。这样可确保模型读取原有词时表现与预训练无异。

2. **冻结与微调**：在训练过程中，可选择冻结绝大部分原模型参数，仅训练新增的嵌入参数和少量与坐标相关的参数（如损失函数中的温度\$T\$等超参）。也可以采用微调策略，但原则上不大幅改动原有参数分布，防止破坏预训练的语言和视觉知识。

3. **功能开关**：设计配置开关以确保兼容性。当坐标令牌功能关闭时，模型忽略/不使用新增词表和损失，退化为普通的视觉语言模型行为；当开启时，模型才进行相应的扩展处理。这样保证了**向后兼容**：旧任务或不需要定位功能的场景，模型依然可以按照原始架构工作。

**技术优势**：

* **保留知识**：由于没有改动LLM主体的权重，预训练所得的大量语言理解和视觉语义知识得以保留。模型不会因为适配新任务而遗忘原有能力，这对需要一模多能的通用视觉语言模型尤为重要。
* **参数高效**：仅增加与坐标令牌相关的极少量参数（例如几千维的新嵌入向量，相对于数以亿计的模型参数可以忽略不计）。因此模型大小几乎不变，计算开销增长也很有限，满足工业应用中对效率的要求。
* **简洁易实现**：无需对模型架构做复杂改造，利用深度学习框架的词表扩展接口即可轻松实现本发明方案。这也提升了方案的可行性和工程落地效率。

### 3.3 数据格式转换技术

在训练和推理中，需将数据在**数值表示**和**令牌序列**之间来回转换。本发明提供了一套数据格式转换方法，确保数值标注的数据可直接用于训练，模型输出的令牌可还原为数值结果。

**训练前处理**：对于训练数据（如图像及对应的目标描述和边界框标签），首先将边界框坐标进行归一化处理（假定已知图像宽高，将像素坐标转为0\~1区间）。然后对每个边界框的坐标按照词汇表的量化规则转换为坐标令牌ID：

* 计算量化刻度：\$id\_x = \text{round}(x\_{\text{norm}} \times (N-1))\$，其中\$N\$是坐标bins总数（如2048）；\$x\_{\text{norm}}\$为归一化后的x坐标（0\~1）。对\$y\_{\text{norm}}\$和对角点的\$x2,y2\$类似计算。
* 将所得\$(id\_{x1}, id\_{y1}, id\_{x2}, id\_{y2})\$映射为对应的令牌 `<coord_id>` 字符串。将这些令牌插入到文本描述中，并在首尾添加 `<|box_start|>` 和 `<|box_end|>` 标记。

例如，原始标注：

```json
{"description": "图中有一个螺丝。", "bbox": [0.1, 0.2, 0.15, 0.25]}
```

表示图像中有一个螺丝，其边界框坐标为\$(x1=0.1, y1=0.2, x2=0.15, y2=0.25)\$（归一化值）。转换后得到模型输入文本：

```
图中有一个螺丝。 <|box_start|> <coord_204> <coord_409> <coord_307> <coord_511> <|box_end|>
```

其中`<coord_204>`表示0.1在0\~2047离散空间对应的刻度（约为204），以此类推。

若一张图像有**多个物体**，则对每个物体各自生成这样一段序列，并可以在描述中依次串联多个 `<|box_start|> ... <|box_end|>` 片段来表示。这种顺序可以根据需要选择（例如按对象类别、位置，或随机顺序，以避免模型偏见）。训练时，模型将整段包含多个标注序列的文本作为目标去拟合，从而学习同时输出多个检测结果的能力。

**推理后处理**：在推理阶段，模型会生成一串文本，其中包括描述性语言和坐标令牌。为了提取数值结果，需要解析生成的文本：

1. 扫描生成文本，寻找所有 `<|box_start|>` 和 `<|box_end|>` 对。每找到一对，即表示一个预测的边界框序列。
2. 对于每个序列，读取其中的四个 `<coord_*>`标记，将每个标记中的数字提取出来，得到对应的刻度值。如 `<coord_204>`提取出数字204。
3. 将刻度值反归一化为0\~1浮点数：\$x\_{\text{pred}} = \frac{204}{N-1}\$（对于ID=2048表示1的情况，确保除以2047）。同理得到\$y\_{\text{pred}}, x2\_{\text{pred}}, y2\_{\text{pred}}\$。
4. 根据需要（如果最终需要像素坐标），再乘以图像原始宽高尺寸，得到图像坐标下的预测边界框。

通过上述步骤，即可从模型生成的文本中还原出所有预测的边界框数值。这种后处理相对简单，因为模型输出已经将结构用标记严格限定，可以用正则表达式等可靠地抽取信息。

## 4. 有益效果

### 4.1 技术优势对比

与传统的基于独立检测头的方案相比，本发明基于软期望的方案在多个方面具有突出优势：

此外，相较于此前的Pix2Seq等纯序列方案，本发明通过软期望进一步突破了离散表示的瓶颈。Pix2Seq采用量化token配合交叉熵训练, 本发明则引入连续期望和专门损失，使模型在**精度**和**训练信号质量**上都有提升，真正发挥出LLM在数值推理方面的潜力。

### 4.2 效果提升

本发明方法为视觉大语言模型在数值处理和定位任务上带来了以下显著提升：

1. **定位精度更高**：利用高分辨率坐标token和软期望计算，实现了近似连续的坐标输出，极大提高了边界框预测的精度。实验中可达到与像素级别回归相当的准确性。同时，通过概率分布刻画预测不确定性，可进一步提高在边界条件下预测的可靠性。

3. **系统复杂度降低**：省去了独立检测分支和复杂损失调优，大大简化了工程实现。开发者无需为不同任务定制不同架构，一个模型通过词汇扩展即可支持多种任务，减少了系统维护成本。

5. **广泛的应用前景**：本发明方法通用性强，可应用于多种视觉场景。例如：

   * 在**工业质检**中，需要识别并定位产品缺陷或部件位置，本方案可凭借高精度和不确定度量化提升检测可靠性。
   * 在**自动驾驶**领域，可将行人、车辆的检测结果以自然语言和坐标形式提供给决策模块，实现可解释的环境感知。
   * 在**机器人视觉**中，通过语言与坐标的统一输出，让机器人更直观地理解指令（如“拿起红色盒子”，同时给出盒子的位置坐标）。
     由于其与预训练模型兼容且参数开销小，本方案易于部署在实际系统中，为各行业的智能视觉应用提供了一种高效、可行的新思路。

### 4.3 实用性与可行性说明

本发明强调在保持理论创新的同时，确保方案的实用性和易实现性：

* **模块化集成，易于落地**：方案各模块（词汇扩展、损失函数、数据处理）清晰独立，可以逐步集成到现有系统中。开发者可先行试验词汇扩展与软期望损失在小规模任务上的效果，再推广应用。
* **兼容现有框架**：实现上充分利用了主流深度学习框架的特性（如可动态扩充词表的Transformer实现）。不需要特殊硬件或底层修改，常规GPU/TPU环境即可运行，降低了部署门槛。
* **可调参数**：提供多项超参数配置（如温度\$T\$、focal loss的\$\alpha,\gamma\$、损失权重等），允许根据不同应用场景调优，以满足精度或速度等不同需求。这些参数在实践中有明确含义，调节相对直观。

综上，本发明在提供创新性的同时，充分考虑了实用落地需求，具有较高的工程可行性和应用价值。

## 6. 具体实施方式

### 6.1 模型配置模块

为方便控制新增功能，本发明提供一个模型配置模块，用于管理与坐标令牌相关的参数。可以采用结构化配置对象的方式，例如：

```text
CoordinateTokenConfig:
    enable_coordinate_tokens: True           # 是否启用坐标令牌功能总开关
    max_coord_value: 2048                   # 坐标量化的精度（最大取值2047表示归一化坐标1.0）
    regular_loss_weight: 1.0               # 普通语言损失权重
    coordinate_loss_weight: 1.0            # 坐标损失权重
    soft_expectation_temperature: 1.0      # 软期望Softmax温度T
    focal_loss_alpha: 0.25                 # 焦点损失α参数
    focal_loss_gamma: 2.0                  # 焦点损失γ参数
    enable_multi_geometry: False           # 是否支持多种几何形状
    bbox_giou_weight: 0.5                  # (可选)边界框GIoU损失权重，用于提高大框重叠度预测
    # ... 其他所需参数
```

开发者可通过修改配置开启/关闭坐标令牌功能，调整量化精度和损失比重等，以适应不同应用需求。配置对象在模型初始化时传入，使模型和数据处理器据此自动完成相应设置。

### 6.2 模型和数据处理器的初始化

利用上述配置，可以方便地初始化支持坐标令牌的模型以及数据处理工具。以一个预训练的V-LLM模型为例，初始化流程如下（伪代码）：

```text
# 1. 创建配置实例并设置所需参数
coord_config = CoordinateTokenConfig(
    enable_coordinate_tokens = True,
    max_coord_value = 2048,
    focal_loss_alpha = 0.25,
    focal_loss_gamma = 2.0,
    # ... 其他参数按需设置
)

# 2. 初始化带坐标扩展的模型
model = PretrainedVLMModel.load("/path/to/model")
if coord_config.enable_coordinate_tokens:
    model.extend_vocabulary_with_coordinate_tokens(coord_config.max_coord_value)
    model.set_coordinate_loss_parameters(
        temperature = coord_config.soft_expectation_temperature,
        focal_alpha = coord_config.focal_loss_alpha,
        focal_gamma = coord_config.focal_loss_gamma,
        loss_weights = (coord_config.regular_loss_weight, coord_config.coordinate_loss_weight)
    )

# 3. 初始化数据处理器
processor = VLDataProcessor(tokenizer=model.tokenizer, coord_config=coord_config)
```

上述步骤中：

* `extend_vocabulary_with_coordinate_tokens`内部执行词汇表扩展和嵌入层扩展（参考3.2.1节），为模型加入新的坐标令牌。
* `set_coordinate_loss_parameters`设置模型内部混合损失计算模块所需的参数，包括温度、焦点损失超参和损失权重等。
* 数据处理器`VLDataProcessor`负责在数据加载时调用相应函数将bbox坐标插入文本或将模型输出解析为bbox（可在其内部实现3.3节描述的逻辑）。

### 6.3 模型训练过程

有了统一的架构和损失设计，模型训练过程可以采用标准的语言模型训练范式。伪代码如下：

```text
for each batch in training_dataloader:
    inputs, labels = processor.prepare_batch(batch_data)
    outputs = model(inputs, labels)
    loss = outputs.total_loss       # 模型内部已根据混合损失计算总损失
    optimizer.backward(loss)
    optimizer.step()
    optimizer.zero_grad()
```

其中，`prepare_batch`方法会对原始数据进行令牌化和格式转换，确保`labels`中含有正确的坐标令牌序列。模型前向计算不仅产生常规输出，还在内部根据标签自动计算出`total_loss`（利用混合损失函数模块）。这样，训练循环无需写复杂的多任务损失计算逻辑，与普通语言模型训练代码几乎无异，体现了本方案**训练范式的统一性和简洁性**。

需要说明的是，如果采用**非破坏性扩展**策略，在训练初期可能只训练新增参数（如新嵌入和坐标相关参数），逐步解冻部分原模型层以适应新任务，从而达到稳定且高效的迁移学习效果。

### 6.4 模型推理过程

当模型训练完成后，可用于推理，即给定图像（和可选的文本提示）输出描述和坐标。推理阶段主要包括模型生成和结果解析两个步骤：

1. **模型生成**：将图像输入视觉编码器，将提示（若有）通过文本编码器编码，然后触发模型的自回归生成过程，一次输出一个token，直到生成结束标志（如特殊的EOF或达到最大长度）。生成结果是一个包含描述性文本和坐标标记的序列字符串。

2. **结果解析**：遍历生成的字符串，按照`<|box_start|>`/`<|box_end|>`结构提取所有预测的边界框：

   * 对每段框序列，读取其中的坐标token，提取数字ID并除以最大刻度（如2047）得到归一化坐标值。
   * 将归一化值乘以原图尺寸恢复像素坐标（如果需要）。
   * 将这些坐标与文本描述关联，得到最终模型输出。如模型输出：“**图中有一只猫** <|box\_start|> `<coord_512>` `<coord_384>` `<coord_768>` `<coord_640>` <|box\_end|>”，解析后可形成结果：描述“图中有一只猫”，bbox预测为(0.25, 0.1875, 0.375, 0.3125)对应于图像相对坐标。

通过上述流程，用户可方便地从模型获取**文字说明+定位**的复合结果。如果模型输出多个目标，各个目标序列均会被解析出来，组成目标列表。这种输出形式直观且信息丰富，满足诸如检测、描述、问答等多重需求。推理过程中产生的**坐标概率分布**如果需要也可一并输出用于分析，但通常只需输出期望坐标即可满足大部分应用。
