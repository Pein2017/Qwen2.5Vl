## 鉴权

所有请求接口都需要鉴权，鉴权方式如下。

输入参数中增加签名字段，签名生成方式将输入参数转换成字符串拼接起来，进行降序排序，然后计算MD5值，客户端服务端比对签名是否一致，同时校验api_id是否和服务中的id一致，进行鉴权

```jsx
def authentication(params: dict):
		if params['appId'] not in []:
				return ''
    auth_str = ''
    for k, v in params.items():
        if k != 'sign':
            auth_str += f'{k}' + f'{v}'
    auth_str = "".join(sorted(auth_str, reverse=True))
    md5 = hashlib.md5()
    md5.update(auth_str.encode('utf-8'))
    encrypted_text = md5.hexdigest()
    return encrypted_text
```

**查询支持语言列表**

```jsx
GET  /v1.0/g2p/langs  请求g2p支持的语言类别
```

请求参数 

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| secret | str | 鉴权签名，生成方法参照 **鉴权** |
| uuid | str | 当前请求唯一id |
| timestamp | str | 当前发送请求时间戳，年-月-日 时:分:秒.毫秒 eg：”2024-01-08 08:30:29.234” |

响应参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| code | str | 响应状态码，参考 **状态码**  |
| message | str | 响应信息 |
| data | object | 响应结果 |
| langs | object | 支持的语言类型 |
| secret | str | 鉴权签名，生成方法参照 **鉴权** |
| uuid | str | 从输入参数uuid获取 |
| timestamp | str | 当前发送请求时间戳，年-月-日 时:分:秒.毫秒 eg：”2024-01-08 08:30:29.234” |

**文本识别**

```jsx
POST  /v1.0/g2p/{lang}  请求注音预识别结果
```

请求参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| lang | str | 文本语言类型，参照输入json |
| text | str | 需要识别的文本内容 |
| types | list | g2p: 注音，rhy: 韵律 |
| secret | str | 鉴权签名，生成方法参照 **鉴权** |
| uuid | str | 当前请求唯一id |
| timestamp | str | 年-月-日 时:分:秒.毫秒 eg：”2024-01-08 08:30:29.234” |

响应参数

| 参数名称 | 参数类型 | 参数说明 |
| --- | --- | --- |
| code | str | 响应状态码，参考 **状态码**  |
| message | str | 响应信息 |
| data | object | 响应结果 |
| content | str | 原始输入文本 |
| g2p | str | 拼音预识别结果，根据输入决定是否输出 |
| rhy | str | 韵律预识别结果，根据输入决定是否输出 |
| secret | str | 鉴权签名，生成方法参照 **鉴权** |
| uuid | str | 从输入参数uuid获取 |
| timestamp | str | 年-月-日 时:分:秒.毫秒 eg：”2024-01-08 08:30:29.234” |

样例

```jsx
请求url: http://ai.datatang.com/v1.0/g2p/ch
请求json：

}

	"code": "200",

	"data": {
		"content": "这是一个测试用例",
		"g2p": "zhe4 shi4 yi2 ge4 ce4 shi4 yong4 li4",

	},
	secret: "xxxxxxxxxxxxxxxxxx",

}
```
